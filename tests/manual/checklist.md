# Checklist de testes manuais

Data: ____ | Testador: ____ | Dispositivo/navegador: ____

## Navegação geral
- [ ] O menu superior aparece em todas as páginas
- [ ] Os links Início, Aulas e Pesquisa levam à página correta
- [ ] A página atual fica destacada no menu superior

## Página inicial
- [ ] Os botões do topo levam a Aulas e Pesquisa
- [ ] Os cards de tópicos levam à primeira aula de cada tópico
- [ ] As perguntas frequentes abrem e fecham
- [ ] Nenhum texto provisório ("Integrante 1", "Nome da instituição") restou

## Aulas
- [ ] Ao entrar em Aulas, a primeira aula abre sozinha
- [ ] Clicar em uma aula troca vídeo, título e resumo
- [ ] A aula atual fica destacada no menu lateral
- [ ] O vídeo toca e a tela cheia funciona
- [ ] Um endereço de aula inexistente mostra a mensagem de erro
- [ ] Atualizar a página (F5) mantém a mesma aula

## Pesquisa
- [ ] O formulário aparece embutido e é possível respondê-lo
- [ ] O link "Abra em uma nova aba" funciona

## Responsividade e desempenho
- [ ] No celular, o menu de aulas abre e fecha pelo botão
- [ ] Não há rolagem horizontal em nenhuma página
- [ ] Testado em celular real, com dados móveis
- [ ] Testado em pelo menos dois navegadores

## Acessibilidade básica
- [ ] É possível navegar pelas páginas usando só o teclado (Tab/Enter)
- [ ] O texto tem contraste suficiente e é legível
